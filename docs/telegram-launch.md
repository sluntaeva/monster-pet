# Подключение Monster Pet к Telegram

## Что подготовлено
Команды `/start`, `/play`, `/help`, сообщение с кнопкой открытия Mini App, меню «Играть», проверка initData на backend и профиль по Telegram ID. Бот отвечает только на команды в личной переписке. Код готов, но реальный бот ещё не создан, токен и HTTPS-хостинг не настроены. Публикация не выполнена.

## Первый шаг: создать бота
1. Открыть официального [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправить `/newbot`, выбрать название и свободный username, заканчивающийся на `bot`.
3. Полученный токен записать только в `BOT_TOKEN` локального `.env` в папке Monster Pet. Не отправлять токен в чат и не добавлять в Git.

Файл `.env` исключён из Git. `.env.example` показывает поля конфигурации. Локальная игра через START.cmd продолжает работать без созданного бота.

## Второй шаг: публичный адрес
`http://127.0.0.1:5173/` доступен только на компьютере и не является адресом Mini App для Telegram. Нужен реальный HTTPS-домен, на котором работают и клиент, и `/api` с этим backend. Одной загрузки index.html на статический хостинг недостаточно.

Выбрать хостинг для Node.js 22.17+ с постоянным диском под SQLite и HTTPS. Разместить проект, установить зависимости (включая tsx), выполнить `npm run build`. Настроить reverse proxy: `/api` → 127.0.0.1:3001, остальные пути → содержимое dist. Точный способ зависит от выбранного хостинга. Автоматически хостинг не создавался и платные ресурсы не заказывались.

В `.env` на сервере: BOT_TOKEN, APP_URL (полный HTTPS-адрес игры), APP_ORIGIN (его origin без пути), NODE_ENV=production, DEV_AUTH=0. При публикации отдельная серверная база, dev-прогресс автоматически в Telegram-профиль не переносится. Сначала проверить `/api/health` через публичный адрес.

## Третий шаг: включить кнопку
Из папки проекта запустить `npm run bot` или START-TELEGRAM.cmd. Скрипт проверит токен, наличие webhook, затем установит меню «Играть» и команды бота. При существующем webhook остановится без удаления настроек. Одновременно должен работать только один polling-процесс этого бота. Для production ему нужен постоянный запуск через менеджер процессов.

Открыть ссылку на бота, напечатанную скриптом, и отправить `/start`. Нажать «Играть в Monster Pet». Меню «Играть» останется настроенным, но ответы на /start требуют работающего процесса бота.

При необходимости настроить Main Mini App в BotFather, указав тот же URL; это отдельная настройка профиля и прямого запуска. Скрипт автоматически её не включает.

## Что проверить
- Первый Telegram-вход → тест → выбранный герой.
- Повторный вход → тот же герой, монеты, покупки и дружба.
- Android/iOS: нижняя панель, safe area, звук, управление пальцем.
- После закрытия/открытия игры авторизация проходит заново по свежему initData.
- В production локальный dev-вход запрещён.

Основа: [Telegram Mini Apps](https://core.telegram.org/bots/webapps), [Bot API — setChatMenuButton](https://core.telegram.org/bots/api#setchatmenubutton). Проверено по документации 2026-10-21. Реальный сквозной запуск пока ожидает создания бота и размещения игры.
